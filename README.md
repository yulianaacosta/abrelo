# Ábrelo

App privada de la familia para abrir y editar PDF y otros archivos, sin anuncios y sin internet.

**Instalar o actualizar:** descarga `abrelo.apk` de la última versión en *Releases* y ábrelo en el teléfono.
La primera vez Android pedirá permitir "instalar apps desconocidas" para el navegador o el gestor de archivos.

Cada cambio que se sube a `main` crea una versión nueva automáticamente (GitHub Actions).
